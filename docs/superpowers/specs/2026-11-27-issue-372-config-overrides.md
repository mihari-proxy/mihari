# 实例配置覆写与运行配置预览

#372 解决订阅缺少 DNS 设置时的持久化配置问题。用户已选定配置覆写页、Authentication 双入口、DNS 表单和有序 YAML 片段。生成顺序与语法以 [ADR 0013](../../adr/0013-instance-config-override-order.md) 为准。

## 用户操作

用户在配置覆写页选择 Authentication、DNS 或 YAML 片段。两个认证入口共享已有认证编辑器和数据。认证密码与用户名的合并、免认证模式以及 CLI 的凭据显隐操作继续沿用。重置表单恢复到应用完片段的基础配置。来源应能区分订阅、片段和表单。

DNS 的布尔字段和模式提供沿用、设置和移除，列表另可追加到已有值和按值移除。显式空列表和删除整个键在预览中有不同结果。对最终 DNS 配置作组合校验，订阅或片段提供的解析器都计入校验。无覆写的旧订阅沿用既有生成行为。

片段支持新增、粘贴、从本地文件导入、重命名、编辑原文、启停、排序和删除。客户端发送内容，daemon 保存原文。按原文顺序解释不同操作键，相同原始键重复按 YAML 重复键报告。列表前插和后追加保留顺序与重复值；删除移除所有完全匹配项。不存在的目标可新建，删除缺失项无副作用。显式整块替换的值是原生 YAML 数据；递归合并才逐层解释操作符。保留原订阅与缓存。

## 边界与状态

持久化采用现有 settings 的可选 config-overrides 块，片段稳定 ID 独立于名称与顺序。默认与清空状态省略新块；沿用旧认证块。旧版严格解码器的降级清理和既有大小上限适用。

始终受保护的键为 mode、log-level、mixed-port、bind-address、allow-lan、external-controller、secret、external-ui、external-ui-name 和 external-ui-url。tun.enable 按现有设置在最终生成时应用，其他 tun 字段和原生扩展字段沿用。覆写以 Mihari 现有托管所有权为准，按解析后实际目标检查；DNS 和认证表单可覆盖片段。Web gateway 权限保持既有范围。本地协议按 capability 增加读取、单类保存和只读预览，不向浏览器返回运行配置或 controller 凭据。

草稿预览与真实生成共用同一份订阅和 settings 快照。相对已保存值展示差异与来源；完整视图由同一候选产生。原认证预览保持字段范围。默认遮罩认证密码，两种视图保持同一显隐状态；完整预览隐藏托管 controller secret。认证本地编辑器保留片段原文。草稿或来源变化后丢弃过期结果。保存前核对 revision 和输入身份，在线校验、替换、reload、持久化失败走现有补偿路径，停机时按现有候选能力保存。提交前失败保留草稿及上一有效配置；settings 已提交后的同步 warning 继续按成功发布。只校验本次有效候选；停用或清除失效片段能恢复配置，保存独立于预览请求是否成功。

## 验收

订阅刷新、切换、重启和设置变动重新走同一生成链。用隔离的缓存、fake core、认证本地 IPC 和 TUI 消息验证优先级、快照一致性、无活动订阅、失败恢复、入口等价与快捷键。测试与发布覆盖现有三个平台的目标。
