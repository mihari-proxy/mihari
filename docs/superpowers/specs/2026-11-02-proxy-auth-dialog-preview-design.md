# Proxy Authentication 弹窗与配置预览设计（已批准）

## 用户已提出的需求

- Proxy Authentication 弹窗增加与 Outbound Interface 弹窗一致的边框。
- 每种模式均提供模式说明。
- 弹窗分为两列：左侧调整参数，右侧展示模拟生成配置中的关键认证片段。
- 右侧高亮当前选中参数对应的变化。

## 设计边界

沿用既有实例代理认证、代理用户与运行配置术语，见根目录 CONTEXT.md。既有认证语义见 2026-10-23-proxy-authentication-design.md；本轮尚未提出变更认证语义。

## 第一轮已确认

- 右侧为只读预览；显示英文提示：`Preview only. To edit the configuration directly, use a local YAML file in Subscriptions.`
- 当前焦点参数影响的配置行使用背景高亮；相对已保存配置的未保存变化使用 `+ / −` 标记，两者区分。
- 模式行后始终显示当前模式的简短说明，随模式切换更新；说明使用英文、浅灰色。
- 密码默认遮罩；Ctrl+R 主动显示，两列显示状态同步。遮罩时说明占位符不代表实际生成值。
- 宽窗口两列；窄窗口上方参数、下方预览，保留边框与焦点高亮。

## 第二轮已确认

- 新增认证本地 IPC 的只读草稿预览能力，由 daemon 结合当前订阅和草稿复用真实认证生成逻辑，只返回认证相关片段；不保存、不 reload、不向 Web gateway 开放。用户已确认该协议扩展范围，保留既有接口语义。
- 用户名、密码、CIDR 等输入期间实时更新预览，允许短暂合并连续输入请求。
- 无效输入显示具体原因；如保留上次有效预览，必须明确标为过期，不能将其呈现为当前草稿结果。
- 认证关闭时保留已保存参数，并以浅灰英文标注 `Authentication disabled`，不使用 `Inactive`。选中这些参数时解释当前不会改变认证结果，不虚构配置增删。
- 上述文案只表达认证关闭原因；沿用订阅等其他未应用原因不能标成 `Authentication disabled`。

## 实现事实

- 当前认证状态接口返回的是已保存设置处理后的有效用户与免认证名单，不包含可用于任意草稿重算的完整订阅原始认证内容。
- 现有本地认证 API 只有状态读取与保存，没有草稿预览接口。TUI 不能自行读取 daemon 的业务缓存。
- 精确预览需要由 daemon 使用订阅原始内容和草稿复用认证生成逻辑。此只读协议扩展范围已获用户确认。

## 第三轮已确认

- 无活动订阅时，以空订阅为基础计算实例认证预览，并显示 `No active subscription. Preview uses instance settings only.`；开启认证但没有用户时显示校验错误。
- 区分字段缺失与显式空列表。缺失字段使用浅灰注释，例如 `# authentication: not set`；实际生成空列表则显示 `authentication: []`。`skip-auth-prefixes` 遵循相同规则。
- 选中左侧参数时，右侧自动滚动至对应配置行；Tab 切换两侧焦点，右侧支持方向键与 PgUp/PgDn 滚动，底部显示快捷键提示。

## 实施与验证要求

- 继续保留既有认证模式、用户合并、免认证规则、保存与回滚语义。
- 预览比较同一份订阅输入上的已保存设置与当前草稿，避免订阅来源变化被误标成草稿修改；结果关联草稿请求与来源版本，丢弃旧请求结果。
- 编辑子项未确认前仅参与预览；取消该项编辑后恢复对应预览，不通过预览写入或应用草稿。
- 密码遮罩不能改变行对应关系或泄露差异中的旧密码；Ctrl+R 的显示状态同时作用于预览中的新增与删除内容。
- 按 TDD 覆盖只读预览、真实生成语义一致性、密码默认遮罩与显式显示、无效输入、异步结果顺序、字段缺失、无订阅、焦点高亮与差异标记、滚动及宽窄布局。
- 测试仅使用临时目录、合成凭据和本地 fake，不访问真实订阅、用户配置或系统服务。
