## 已确认的设计

- Q1：自动测速采用类似图片懒加载的可见性触发。展开分组后，节点卡片进入屏幕可见区域才触发首次自动测速；展开但尚在屏幕外的节点不提前触发。
- Q10 明确了选中节点的触发范围：视口内组头 Now 对应的最终节点（即使该组折叠），以及顶部 Basic 的 GLOBAL 当前节点，也触发自动测速。同一最终节点在一轮内只自动测一次。
- Q2：若当前选中成员是代理组，沿各组的当前选择继续查找最终实际节点，对该节点测速并复用结果显示额外延迟。
- 截图中 `→ Jump to Selected` 的箭头属于定位按钮，不表示连接或选择链；延迟位于当前名称之后、定位按钮之前。定位按钮保持原有含义。
- Q3：每次进入 Proxies 都重新测速。每次进入建立新的首次记录范围，并继续遵循 Q1 的可见性懒加载；不会因为开始新一轮而提前测试屏幕外的全部节点。同次停留内，已触发过的节点再次进入可见区域不重复自动测速。
- Q4：额外延迟显示、自动测速两个开关跨 TUI 重启保存，由 daemon 负责持久化。用户已明确接受为这两个开关扩展偏好格式及本地协议；授权限于本项功能所需字段及保存行为。
- Q5：额外延迟显示、自动测速两个开关都默认开启。关闭额外延迟显示只隐藏 Routing GLOBAL 与代理组当前值旁的额外延迟，节点卡片仍显示测速结果。
- Q6：页面配置快捷键为 F4。后续需求将其扩展为所有主页面共用的入口，侧栏和内容区均可触发；底部提供提示，已有弹窗优先接收按键。
- 顶部区域标题由 Routing 改为 Basic。页面设置入口放在第二列第一行（与左侧 Mode 同行），可通过光标聚焦并用 Enter 打开与 F4 相同的设置弹窗。GLOBAL 继续位于左侧第二行；不将设置入口放在第三行。
- 页面配置采用全局统一弹窗，按页签划分多个 Section，沿用侧栏顺序。每次从某页打开时，展开该页对应的 Section，并使其标题可见且获得焦点，其他页的 Section 默认折叠。用户可在弹窗中访问其他页配置。
- Q7：本次其他页面先不做配置项，保留对应 Section，展开时显示准确文案 `No settings available yet`。
- Q8 结构已确认：弹窗两列，左侧为 Section 列表，右侧为包含所有 Section 的连续配置区域；左侧作为跳转目录，将光标快速移到右侧对应 Section 的 header，而不是筛选或替换右侧内容。
- Q9：弹窗统一 Save / Cancel，修改保留为草稿，Save 成功后保存并生效；Esc 放弃。跨 Section 浏览及展开/折叠不丢失草稿。
- Q8 视觉已选 C：左侧 Section 目录与右侧连续配置区之间使用竖向分隔线，右侧采用轻量标题/分隔线，不给各 Section 增加独立卡片边框。Save / Cancel 固定在弹窗底部。
- 增加 Ctrl+S 保存快捷键，可从弹窗任意焦点位置提交与 Save 相同的草稿；在 Save 旁以浅灰色显示 `Ctrl+S` 提示。用户要求底部按钮可快速到达，不必先遍历最后一个 Section。
- 导航已确认：Tab 按左侧目录、右侧配置区、Cancel、Save 循环，Shift+Tab 反向；左右列表各自作为一个 Tab 停靠点，保留内部焦点。右侧任何标题或配置项上按 Tab 均直接到 Cancel，再按一次到 Save。↑/↓ 负责当前列表内移动；底部 ←/→ 在 Cancel 与 Save 间切换，Enter 激活按钮。Ctrl+S 保存提示使用浅灰色，不参与 Save 按钮的焦点高亮。
- Q11：从其他页切到 Proxies 就开始新一轮，焦点仍在侧栏也生效；侧栏和内容区互换焦点、打开/关闭设置弹窗不新开一轮。离开 Proxies 或保存关闭自动测速时停止自动任务；重新进入或重新开启时开始新一轮。同页期间切换订阅或核心重启后也重新开始。
- Q12：节点卡片内容部分进入视口就算可见；已见节点进入本轮测速队列，随后滚出视口也继续完成，未见节点不提前测速。
- Q13：用户明确选择直接覆盖，沿用既有测速状态和结果覆盖流程，不新增每轮开始时清空延迟或标记旧结果的展示逻辑。新一轮只重置首次触发记录；实际开始测试时沿用转圈状态，收到结果后覆盖为延迟或错误。成功沿用卡片的单位和配色，失败沿用 Timeout / Failed 等已有表示；同轮不自动重试，用户可手动重测或下次进入再测。额外显示与卡片共用结果。
- Q14：左侧 ↑/↓ 选 Section，Enter 跳转并展开目标 Section，光标移到右侧目标标题，其他 Section 折叠状态不变。右侧标题 Enter / Space 展开折叠，开关 Enter / Space 切换；右侧光标移动至其他 Section 时，左侧目录同步高亮对应 Section。联动依据光标所在 Section，不用纯滚动替代焦点变更；停靠底部按钮时保留最近的 Section 指示。

## 持久化实现约束

- 复用既有 TUI 偏好控制路径及统一 mutation coordinator，TUI 不直接写偏好文件。
- 沿用现有偏好的作用域：同一 daemon/数据根的 TUI 客户端共享已保存偏好，不新增按客户端用户划分的配置存储。
- 扩展时须保留现有连接表列配置；保存连接表列配置也不得覆盖两个新开关。
- 新字段缺省时两个开关均为开启；显式 false 必须能持久化，不能被缺省逻辑覆盖。请求省略的页面偏好保留当前值，不能通过整份替换恢复为默认。
- 同步核对偏好加载、默认值、更新及安装迁移校验，避免新字段造成偏好丢失或迁移失败；保留已有 revision 冲突检查，不静默覆盖并发更新。保存失败保留弹窗草稿并显示错误，保存中防止重复提交，成功后发布已提交偏好。

## 实现与验收边界

- 测速复用现有本地控制客户端、名称去重策略和最多 5 路并发；手动测速入口继续可用，自动测速关闭不禁用手动测速。
- 自动任务须有明确取消路径和轮次校验。上一轮或旧订阅/核心的延迟结果不得覆盖新任务的状态；这是异步正确性约束，不是额外的旧延迟展示逻辑。
- 分组当前选择解析需防循环及缺失成员，不为了展示延迟递归发起重复测试。目标无法确定时不展示另一个节点的结果。
- 延迟插在当前名称之后、Jump to Selected 按钮之前。Basic GLOBAL 的延迟与该行实际展示的目标一致，不能将保存目标与实时目标混配。
- 窄终端内对名称按显示列截断，避免延迟、定位按钮或提示越过边框；Basic 保持两行、设置入口保持第一行第二列。配置弹窗右侧可滚动，底部按钮固定，保持 C 的双列结构并适应支持的窗口尺寸。
- 页面设置仅纳入 Proxies 两个开关，其他 Section 显示占位文案；不迁移 Conns 列配置、Logs 筛选或 System 业务设置。
- 只使用合成数据与 fake 客户端验证，不连接真实订阅、真实 mihomo 或修改系统服务；用户在实现验证完成后已授权提交、推送、PR 及全绿后的 bypass merge。
