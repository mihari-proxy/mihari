# Proxies 当前组选中元素定位

日期：2026-09-15。
状态：七项交互决策均经用户确认，已按设计实现；执行与验证记录见[执行方案](../plans/2026-09-15-current-proxy-locate.md)。
Issue：[#242](https://github.com/mihari-proxy/mihari/issues/242)。
分支：`feat/242-current-proxy`，基于 `origin/dev` @ `cb08ec2`。

## 目标

- 在代理组标题 `Now: [JP]日本高速…` 的节点名称右侧增加按钮。
- 按钮获得焦点后，按 Enter 将键盘焦点跳转到当前组已选中的元素，并滚动使目标可见。

```text
▾  Now: [JP]日本高速06|BGP|CTCU  [Locate]
```

这里的定位目标是当前组 `Now` 对应的直接候选卡片。定位操作只改变页面的展开状态、键盘焦点与视口。

## 现有实现与文档依据

- `internal/tui/pages/proxies/model.go`：组标题 Enter 展开/折叠，↑/↓移动；组标题左右键目前没有操作。标题始终显示，候选卡片只在展开时显示。
- `internal/tui/pages/proxies/navigation.go`：焦点按组名、节点名标识；节点区域使用方向键进行网格导航。
- `internal/tui/pages/proxies/model.go`：刷新失败保留旧列表，标题 `Now` 改为 `Last selected`；缺少名称显示占位值。
- [Proxies 顶部控制区与 GLOBAL 定位](2026-09-14-proxies-routing-layout-design.md)：现有定位会管理视口范围；长名称按显示宽度截断，优先保留操作提示。
- [节点切换失败反馈](2026-08-14-proxies-select-error-feedback-design.md)：节点选择是独立的异步操作，成功结果更新 Now。

## 已确认设计

1. 按钮命名 `Locate`；标题上 → 聚焦按钮，← 返回标题；标题 Enter 保持展开/折叠，按钮 Enter 执行定位。
2. 折叠组按钮仍可用，执行时自动展开并聚焦当前组选中卡片。如果选中元素是另一个策略组，定位本组内对应卡片。
3. 刷新失败时，旧快照中仍能找到目标就允许定位，并保留现有 Last selected 提示；Now 为空或不在当前候选中时按钮置灰。

4. 布局：`[Locate]` 紧跟名称右侧，同一行显示；宽度不足时截断名称，优先完整保留按钮，沿用现有主题焦点样式。
5. GLOBAL：下方 GLOBAL 组标题也增加 Locate；顶部 Routing 的 GLOBAL 入口继续定位组标题。
6. 动态刷新：Enter 时以页面最新持有的组快照查找目标；定位后刷新不自动追随 Now。聚焦的元素消失时回到组标题。
7. 按钮导航细节：按钮上的 ↑/↓ 沿用所在组标题的纵向导航，Esc 返回侧栏；禁用按钮仍可聚焦以保持导航位置稳定，Enter 无操作。目标卡片完整可见即可，不强制居中；定位成功后继续使用现有节点导航。

### 刷新行为示例

- 最近成功快照中的 Now 为日本06；下一次刷新失败，现有页面保留旧列表并显示 `Last selected: 日本06`。日本06 卡片仍在列表中时，Locate 可用。
- 定位到日本06 后，后续正常轮询得到 Now 为香港02：标题更新为香港02，焦点继续停在日本06；用户再次触发 Locate 才跳到香港02。
- 名称比较和目标查找使用完整节点标识；显示名称的截断不影响定位。

## 实施边界

改动收敛在 Proxies 页面焦点、导航、渲染、相关帮助文案与测试。复用既有控制客户端快照和视口机制，保持 daemon 单写入者边界及现有 CLI、协议、持久化格式。

## 验收范围

- 标题与按钮的左右移动、Enter 行为、按钮 ↑/↓ 与 Esc、禁用按钮焦点及无操作行为。
- 展开组和折叠组的定位；嵌套策略组定位到当前组内对应卡片；GLOBAL 组支持同一交互。
- 长列表目标在视口外时自动滚动；常规视口中卡片完整可见；小于卡片高度的视口沿用现有滚动边界。
- 长名称、中文及 emoji、不同终端宽度；名称截断后按钮仍保留，焦点样式与页面其他控件一致。
- 空 Now、Now 不在候选中、刷新失败保留旧目标、恢复刷新后的按钮状态。
- 按 Enter 前 Now 变化时使用最新快照；定位后 Now 变化不抢焦点；聚焦候选消失时回到组标题。
- 定位不调用代理选择、测速或其他 mutation，不改变实际节点选择；后续节点 Enter 沿用既有选择行为。
