# TUI 检索、连接历史与日志筛选优化

日期：2026-09-17

状态：Q1–Q7 全部获用户确认；已授权完善计划、测试开发、提交 PR 及跟进 CI/bot review 至通过。

工作分支：`feat/tui-search-history-log-filter`，基于 `origin/dev` 的 `1806012`。

执行记录：[执行计划](../plans/2026-09-17-tui-search-history-log-filter.md)。

## 用户明确提出的目标

- Conns、Rules、Logs 页面在保留 `/` 的同时，增加 `Ctrl+F` 快速聚焦检索输入框。
- Conns 的已关闭连接记录保留上限提高到 5000 条。
- Logs 页的 Level 使用小弹窗选择需要展示的日志级别。

## 已确认的设计范围

- 检索：Q1 已确认侧栏/内容区范围、保留查询、光标末尾及弹窗优先级。
- 连接历史：上限 5000，保留现有 FIFO 淘汰与会话生命周期。
- 日志筛选：Q2–Q7 已确认精确级别多选、确认与取消、空选择限制、全选操作、会话记忆范围和摘要压缩。

## 已核对的现状

- Conns 已关闭记录默认上限确实为 500，两处默认值分别位于页面初始化与历史容器。记录来自前一轮活动列表中、本轮已消失的连接；超限淘汰最早追加的记录。
- 连接历史保存在当前 TUI 会话内存中，切页保留；进入重连、终止错误或退出 TUI 后不保留。此次已明确的容量目标为 5000，不自动引入持久化或延长会话生命周期。
- `/` 目前仅在内容区处理；侧栏输入路由没有提供聚焦页面检索框的快捷操作。
- Logs Level 目前按 All、debug、info、warn、error 循环，为精确级别筛选，warning 归一为 warn。
- Logs 显示筛选应用于已有内存记录；底层实时日志流固定按 debug 订阅，页面筛选不修改统一日志级别或订阅阈值。

## 第一轮访谈

1. **Q1 已确认**：Conns、Rules、Logs 中，Ctrl+F 在侧栏和页面内容区均可聚焦检索输入框；保留已有检索文字，并将光标移到末尾。详情或其他弹窗打开时不抢走弹窗焦点。保留 `/` 现有入口。
2. **Q2 已确认**：Logs Level 使用精确级别多选，可同时选择多个需要展示的级别，例如仅 WARN 和 ERROR。选中级别之间取并集，再与文字检索条件取交集。
3. **Q3 已确认**：Level 弹窗内仅编辑候选选择；Enter 应用并关闭，Esc 放弃修改。编辑时不实时改变背景页面的过滤结果。

## 第二轮访谈

4. **Q4 已确认**：至少选择一个级别；空选时 Enter 留在弹窗并提示，不提交空选择。
5. **Q5 已确认**：当前 TUI 进程内保留选择，切页和重连不重置；重启恢复全选，不新增持久化设置。
6. **Q6 已确认并修订**：多选弹窗采用上下移动、Space 勾选、`Select all` 全选/清空、Enter 确认、Esc 放弃。全选操作的标签由建议的 All 改为 `Select all`。打开期间屏蔽数字切页、q、/、Ctrl+F 等切页及页面快捷键，保留已有强制退出路径；关闭后页面 Level 显示已选级别摘要。

## 级别摘要压缩：Q7 已确认

用户要求支持 `DEBUG+`、`INFO+`、`WARNING+` 形式，表示该级别及以上全部被选中；不连续的选择完整列出所选类型。

`+` 是页面 Level 摘要的自动压缩格式，弹窗仍逐项勾选，不额外增加阈值预设选项。按 DEBUG、INFO、WARNING、ERROR 顺序展示；WARNING 对应当前 warn/warning 的同一级别，不改变日志记录内容或协议值。

| 所选级别 | 页面 Level 摘要 |
| --- | --- |
| DEBUG、INFO、WARNING、ERROR | DEBUG+ |
| INFO、WARNING、ERROR | INFO+ |
| WARNING、ERROR | WARNING+ |
| ERROR | ERROR |
| DEBUG、WARNING | DEBUG, WARNING |
| DEBUG、INFO | DEBUG, INFO |

只有从某级别连续选到最高级别 ERROR 的组合才使用 `+`；单独 ERROR 使用原名。

## 实现边界与交互细节

- Ctrl+F 的 shell 路由先尊重全局弹窗，再询问页面能否聚焦搜索；成功时同步切到内容焦点与文本输入模式，避免随后快速输入数字被误认为切页。已在搜索中时同样保留内容并将光标移到末尾。
- Conns 的详情/列选择器、Rules 详情及 Logs 详情/级别弹窗均阻止 Ctrl+F 抢焦点。
- Level 使用居中小弹窗、现有主题和语义颜色；背景变暗。Select all 在部分选中时全选、全部选中时清空。重新打开时载入实际选择并定位首个选中级别；全选时定位 Select all。
- 候选值独立于生效值。选择变化不会影响后台持续接收的日志；确认后按最新缓存重新过滤，并保持原有暂停及跟随模式，焦点回到 Level。
- 全选延续原 All 的兼容语义：不按级别排除记录，未知级别仍可见；部分选中只保留匹配的已知级别。warn/warning 大小写归一。
- F2 全局诊断窗口与 Ctrl+C 退出保持现有行为；级别弹窗屏蔽其余全局导航与页面快捷键。窗口缩小时约束弹窗尺寸，选项可滚动并保持当前项可见。
- 不新增依赖，不修改持久化格式、控制协议、系统日志级别、流订阅阈值或 CHANGELOG。
