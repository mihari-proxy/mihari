## 已确认决策

第一轮用户选择：Q1 C、Q2 A、Q3 B、Q4 B；标签方案以用户后续明确取消 Raw、Proxies 的决定为准。

1. 信息优先级以完整资料为目标，尽量在一屏展示字段，不突出某一排查或流量观察场景。
2. 使用居中紧凑面板，宽屏限制宽度，窄屏随窗口收缩。
3. 采用单页连接详情，移除 Raw、Proxies 页面以及整个标签栏。原 Overview 内容直接作为详情正文，完整代理链使用箭头串联展示，不再显示单独的 Overview 标签。
4. 允许重组信息和浏览交互，包括字段展示、滚动与换行；本次不增加关闭连接、复制字段等操作。

## 实现前核实的基线行为

- 详情随连接快照刷新；列表 Pause 同时冻结详情，刷新保留当前标签及滚动位置。
- Closed 表示连接已从后续快照消失。结束观测时间由 TUI 记录，不能作为内核报告的精确关闭时间；会话内历史最多保留 500 条。
- Closed 记录保留最后观测的速率及累计流量，目前没有清零速率。
- Raw 是 Mihari 的连接记录 JSON，包含本地计算的速率和结束观测时间，不是 mihomo 原始响应，不包含 GeoIP 查询结果。
- 代理链按内核返回的数组顺序保留；现有代码不能证明该顺序就是数据包经过方向。
- GeoIP 在打开详情时查询公开目标 IP 及 Remote 地址。可能存在两条记录，展示时必须能分辨每条记录对应的地址。
- 协议已有开始时间、结束观测时间、进程路径、嗅探域名及累计流量，现有 Overview 尚未展示这些字段。
- 现有按键：Enter/Esc 返回，左右切标签，上下逐行滚动；切换标签会重置滚动位置。

事实来源：`internal/tui/pages/connections/detail.go`、`model.go`、`history.go`，以及 `internal/control/protocol/runtime.go`。

## 已落实的布局与交互

- 单个圆角居中面板，外宽上限 88 列，计入 shell padding；窄屏随可用宽度收缩。
- 固定标题与 Active/Closed/Paused 状态；目标摘要、Traffic、Endpoints、Routing、Metadata 正文滚动。
- 正文至少 64 列时流量并排，否则纵向排列；字段按显示单元宽度换行并对齐，极窄窗口标签和值分行。
- 展示累计流量、嗅探域名、进程路径、入站用户、开始时间及结束观测时间；缺失可选字段省略，其余用 `—`。
- 代理链按原数组顺序保留箭头连接；延续项目既有国旗 emoji 转 `[ISO]` 的显示规则。
- Closed 标记 Last download/upload rate；暂停明确显示 Paused。GeoIP 每条结果保留地址，失败仅显示 Unavailable。
- ↑/↓ 逐行滚动，Enter/Esc 返回；无切页按键。底部位置提示独立预留，resize/刷新限制滚动偏移，极小窗口显示 resize 提示。
- 快捷键只在 shell footer 出现；不增加复制、关闭连接或新的业务操作。
