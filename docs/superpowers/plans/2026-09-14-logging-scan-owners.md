# Full error logging: execution-owner scan

Date: 2026-09-14

## Scope and method

This is the single production-file inventory for `cmd/mihari` and `internal/{app,runtime,daemon,supervisor,platform,service,sysproxy,tundetect,elevate,cli,buildinfo}`. The inventory used `rg --files` once, excluded tests, and covered 277 Go files: app 87, runtime 19, daemon 2, supervisor 9, platform 86, service 19, sysproxy 11, tundetect 10, elevate 3, cli 19, buildinfo 1, and cmd/mihari 11. Candidate searches covered APIError construction, discarded errors, Close/Cleanup/remove fallbacks, redaction, and diagnostic reporter ownership.

The review applies the settled boundary: file diagnostics keep raw causes; public protocol/CLI errors remain concise; an existing file reporter receives owner-only events; nil reporters do not create an outlet.
