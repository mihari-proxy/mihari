# #372 实例配置覆写实施方案

产品规则见 [ADR 0013](../../adr/0013-instance-config-override-order.md)。执行目标涵盖本文的持久化、认证本地控制协议、测试开发、提交和 PR 验证。设计细节见[设计方案](../specs/2026-11-27-issue-372-config-overrides.md)。

## 持久化与版本兼容

沿用 daemon 管理的 `mihari.yaml`，新增可选的 `config-overrides`。其 `fragments` 为有序列表，每项保存稳定 ID、名称、启用状态和 YAML 原文；`dns` 只保存用户显式设置的字段、操作和值。清除某一字段的表单覆写等于移除对应设置，显式要求从生成配置移除字段则保存移除操作。两个认证入口共用现有 `proxy-auth`，认证用户继续按用户名合并。

升级时缺少新字段即表示空覆写，无须迁移。最后一项清除后省略整个新字段。旧版 settings 解码器拒绝未知字段，降级前需要在新版清除 DNS 表单和全部片段，包括停用片段。完整业务重置随 settings 清除覆写，单独重置代理认证保留片段。保存前检查序列化后的 settings 仍在既有 1 MiB 限额内，超限保留旧配置与编辑草稿。

## 认证本地控制协议

拟新增 `config-overrides-v1` capability。通过 `GET /v1/config-overrides` 读取 DNS 设置和有序片段，通过 `PUT /v1/config-overrides/dns`、`PUT /v1/config-overrides/fragments` 分别提交一份完整表单或列表，mutation 携带既有 operation ID 和 revision。认证保存沿用 `PUT /v1/proxy-auth`。保留既有认证预览响应的字段范围和密码显隐语义。

拟新增只读 `POST /v1/config-overrides/preview`，指定编辑类别、草稿及相关或完整视图。daemon 以同一订阅快照计算已保存设置和草稿的最终配置，返回来源与变更。预览需支持对大配置分页，后续页绑定同一草稿与来源版本，快照变化时重新预览。已有 1 MiB 控制请求上限继续适用。完整预览对认证凭据沿用显隐规则，默认隐藏 controller secret；显式认证密码显隐只作用于认证字段。接口仅通过既有认证本地 IPC 提供。旧客户端可继续使用认证接口，新客户端按 capability 显示覆写功能。首期沿用已有 CLI 命令和 JSON envelope，新增交互位于 TUI。

## 实施顺序与验收

1. 在 `internal/subscription` 写表驱动回归用例，再实现按 YAML 节点顺序执行的覆写。覆盖重复值移除、同一列表的先删后加与反序、已有及缺失的映射、字面域名键、顶层及嵌套替换、源订阅保持原样。受保护字段按实际作用路径检查，覆盖整块与特殊键名也应接受相同检查。
2. 让启动、活动订阅刷新或切换、无活动订阅的默认配置、认证状态和预览共用生成规则。验证片段优先于表单，现有出口网卡对最终 DNS 生效，两个认证入口得到相同的用户、来源及凭据结果。用同一草稿验证八项 DNS 的组合约束。
3. 复用 Manager 的候选校验与补偿事务，锁外生成和校验，提交前复核 revision、订阅身份与缓存版本、settings 代次和 core 状态。覆盖在线 reload、失败回滚、保存失败恢复、停机保存及重启重建；校验或 reload 失败时继续使用原有效配置。
4. 接入类型化客户端和 TUI，复用认证编辑器，增加 DNS 表单与片段列表、文件导入和多行原文编辑。导入由本地客户端读取用户选择的文件并发送内容。验证默认折叠、完整预览分页、Ctrl+O 切换和独立的 Ctrl+R 显隐、失效草稿及陈旧异步响应。
5. 各阶段先跑目标包，再跑 fake core 集成测试、全仓测试、race、vet 和格式检查。交付时同步用户文档，说明片段语法、操作顺序、降级清理和凭据可见范围。

## 检查点

- 生成与 settings 的可观察边界是 Generate、settings 严格读写及深拷贝；同名片段、缺失源字段、按值删除后为空、操作符转义和顺序均使用固定输入输出断言。
- 保存事务与协议边界使用 Manager、类型化客户端和 fake core，区分已提交 warning、reload 失败、持久化失败及停机恢复。以最终候选为准；读取预览与保存分别执行。原认证端点的脱敏与凭据来源覆盖两个入口。
- TUI 用真实按键和消息断言页面选择、草稿逐项编辑、按类别整体保存、失败草稿、来源和预览切换。大预览依据实际编码字节分页，来源版本与草稿共同绑定后续页。覆盖大单行、旧值与新值差异分页，先遮罩再编码。覆盖原候选因输入变化失效后仍可停用有问题的片段。
- 最终核对六个 CGO-free 发布目标、相关平台 CI、PR bot 意见及 workflow 状态；处理到 PR 全绿，合并留给用户。

settings 与本地 DTO 表示片段的 id/name/enabled/yaml；DNS 每个字段保存 operation 和匹配类型的 bool、mode 或 servers。操作值 set/append/remove/delete 对应赋值、列表合并、按值移除与整键删除，缺省字段沿用。片段导入只读取一次文件，生成时原生配置路径按 mihomo 原工作目录解析。完整页的各段通过同一来源/草稿指纹衔接，差异与分页均不得回传旧密码或 controller secret。
