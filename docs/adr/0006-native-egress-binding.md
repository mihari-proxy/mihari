# 出口选择复用 mihomo 原生绑定语义

Issue #291 的出口选择属于 Mihari 实例，手动选择覆盖受管配置中冲突的网卡设置，切回自动恢复未设置出口网卡时的既有行为。网卡绑定复用 mihomo 原生能力及其本机通信、协议与调用路径例外；Mihari 不另建 socket 绑定、系统路由或网络隔离机制，因为该功能提供的是受管核心的出口配置与状态管理，而不是对所有流量的操作系统级隔离保证。

这一范围及其产品行为已在[设计访谈](../superpowers/specs/2026-09-21-egress-interface-design.md)的 Q1–Q24 中确认。接口按名称保存；同名恢复沿用内核缓存与池化语义，不额外自动重载或重启。不可用状态不触发回退或主动停核心。这不代表实现或平台验收已经完成。
