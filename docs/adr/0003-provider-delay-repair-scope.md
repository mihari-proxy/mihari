# 修复 provider 测速路由，不扩展同名节点产品能力

provider-only 节点即使名称唯一，也会因 Mihari 调用普通节点测速接口而返回 404；完整的同名节点身份系统不是修复这个缺陷的前提。鉴于 mihomo 的组选择接口只接受名称，用户确认本轮聚焦 provider 节点发现、元数据、正确测速路由及全部 mihomo HTTP 错误诊断，不新增 provider 浏览页或同名节点精确切换功能。同名解析规则需显式确定，不默认照搬其他面板按名称覆盖的行为；CLI/TUI 与 daemon 按用户要求配套升级。本决定替代 ADR 0001 对完整同名支持的范围要求。
