# 不同 provider 的同名节点是不同测速目标

Issue #204 修复中，节点身份必须区分所属 provider，不能将展示名称作为跨来源唯一身份。用户选择本轮支持不同 provider 同名节点分别测速，而不采用同名即拒绝的收窄方案；因此列表、测速调度与结果状态都必须保留这种区分，避免请求发对了但结果写到另一个节点。具体协议字段、旧客户端兼容方式和组内出口选择语义另行设计，本决定不预先选定实现形式。

本轮范围已由 [ADR 0003](0003-provider-delay-repair-scope.md) 替代。跨来源同名节点在概念上不同仍成立，但本轮不提供完整的分别操作能力。
